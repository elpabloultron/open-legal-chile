Compresión de Contexto & Razonamiento Dogmático

LegalGraphify: motor ontológico de grafos para el derecho chileno

En lugar de inyectar hasta 1 612 tokens de tratados crudos en el prompt de tu LLM, LegalGraphify estructura el ordenamiento jurídico de Chile en un grafo de conocimiento formal (12 973 nodos y 28 346 aristas ponderadas). Deduce subsunciones rigurosas, traza rutas de argumentación dogmática y comprime hasta 113,6x el consumo de tokens sin alucinaciones. Incluye un resumen del corpus por comunidades (33 comunidades temáticas) y una Wiki Doctrinal sintetizada de 369 artículos Markdown para agentes.

Paquete independiente & open source Apache 2.0 · v0.9.0
Disponible como biblioteca CLI/Python, servidor MCP y visualizador interactivo en Space

LegalGraphify funciona de manera autónoma en tus propios scripts o integrado nativamente en las 75 herramientas de Open Legal Chile. Salida en YAML denso, JSON estructurado, GraphML, Cypher y modo inferencia en cascada.

Los 5 modos de inferencia relacional

LegalGraphify opera como un motor de razonamiento formal sobre la doctrina, la ley positiva y la jurisprudencia. Cada modo resuelve una necesidad crítica en el flujo de trabajo jurídico con agentes de IA:

1. QUERY · SUBGRAFO [MCP: graphify_consulta_subgrafo]
Extracción de subgrafo sintético

Aísla la institución y su entorno ontológico en un radio de $N$ saltos. Retorna un bloque YAML ultra-comprimido con normas BCN, criterios de la Corte Suprema, vías procesales y tratadistas canónicos.

$ legal-graphify query "simulación" --depth 2
2. PATH · CAMINOS [MCP: graphify_trazar_camino]
Trazado dogmático mínimo

Calcula la ruta relacional más corta entre dos instituciones o normas distantes (por ejemplo, Simulación Contractual → Inoponibilidad), deduciendo la cadena de subsunción procesal sin vacíos lógicos.

$ legal-graphify path "simulacion" "inoponibilidad"
3. EXPLAIN · 360° [MCP: graphify_explicar_institucion]
Explicación canónica integral

Despliega la anatomía canónica completa de una institución: definición doctrinal unificada, fundamento positivo en el Código Civil o leyes especiales, roles jurisprudenciales y centralidad en el grafo.

$ legal-graphify explain "objeto_ilicito"
4. BLAST RADIUS · IMPACTO [MCP: graphify_analizar_impacto]
Simulación de reformas e impacto

Modela el radio de impacto cuando una norma es reformada o derogada. Determina entidades afectadas en Grado 1 (impacto directo) y Grado 2 (cascada sistémica) para auditoría normativa preventiva.

$ legal-graphify affected "Art. 1464 CC" --cascade
5. GOD NODES · PILARES [MCP: graphify_god_nodes]
Pilares dogmáticos estructurales

Aplica algoritmos de PageRank y centralidad de intermediación para identificar los nodos axiales del derecho chileno que sostienen la mayor densidad de conexiones y dependencias normativas.

$ legal-graphify god-nodes --top 10
Ejemplo de uso en Python SDK & MCP Zero Dependencies · Pure Python / JSON 
from legal_graphify import LegalKnowledgeGraph

# 1. Cargar el grafo ontológico canónico
kg = LegalKnowledgeGraph()

# 2. Consultar subgrafo comprimido (-69,1 % tokens en "simulación")
subgrafo_yaml = kg.query_subgraph("simulacion", depth=2)

# 3. Trazar la ruta de subsunción lógica mínima
camino = kg.find_path("simulacion", "inoponibilidad")

# 4. Calcular el radio de afectación ante reformas legales
impacto = kg.analyze_impact("Art. 1464 CC", cascade=True)
