Redacción OJV & Compilador Forense

Generador de escritos judiciales estructurados bajo los estrictos estándares de la Oficina Judicial Virtual (Ley N° 20.886). Compila denuncias y demandas en PDF formal A4 con portadas institucionales, índices y anexos probatorios ensamblados, además de OCR forense con Tesseract para expedientes escaneados.

Instalación Rápida

Instala en el asistente que ya usas.

Open Legal Chile se conecta mediante el protocolo abierto MCP (Model Context Protocol) o CLI nativo. Sin suscripción, sin API keys externas y sin salir de tu entorno favorito.

¿Con qué asistente programas o investigas?

$ openlegal 
$ pip install openlegal-chile
# Iniciar servidor MCP en stdio
$ openlegal-mcp
Compresión de Contexto

LegalGraphify: Consultas Hiper-Densas en Grafo.

En lugar de inyectar 3.500 tokens de tratados crudos en el prompt de tu LLM, LegalGraphify extrae el subgrafo canónico a $N$ saltos en YAML estructurado.
