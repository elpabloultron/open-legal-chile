Instalación, Integración y Uso de Open Legal Chile

Guía práctica con comandos copiables en un clic para conectar las 88 herramientas jurídicas a Antigravity, Claude Code, Cursor, VS Code Copilot, Gemini CLI o tu propio computador offline con Ollama.

⚡ Paso 1: Instalar

Un comando vía pip o ejecución sin instalación con uvx.

🔌 Paso 2: Conectar

Integración automática sin editar JSON a mano (openlegal integrar).

⚖️ Paso 3: Litigar

Lenguaje natural en Mesa de Entrada, verificación BCN/HF y salida Word .docx.

01 · Preparando el Entorno

Qué necesitas antes de empezar (y qué NO hace falta)

✅ Lo que SÍ necesitas

  • Sistema Operativo: Linux, macOS o Windows 10/11.
  • Python 3.10 a 3.14 (o solo tener uv instalado para ejecutar con uvx sin crear entornos).
  • Un harness compatible MCP (Antigravity, Claude Code, Cursor, VS Code, Gemini CLI) o terminal directa openlegal.

🚫 Lo que NO necesitas al iniciar

  • Sin tarjetas ni API keys comerciales obligatorias: BCN, PJUD, CGR, DT, SII, el Grafo y el Mapa HF funcionan sin claves.
  • Sin GPU dedicada: El motor vectorial RRF, FTS5 y LegalOpenJev corren en CPU estándar.
  • Token HF opcional: Solo útil si harás descargas masivas reiteradas desde Hugging Face.
02 · Dos Formas Oficiales de Arrancar

Instalación permanente (pip) o ejecución limpia (uvx)

Opción A · Recomendada en Estudios

Instalación Completa desde PyPI

Instala CLI (openlegal), servidor MCP (openlegal-mcp), configura tu harness detectado y descarga el mapa del corpus.

Bash / PowerShell
pip install openlegal-chile
openlegal instalar
Opción B · Sin Tocar tu Python Global

Modo Efímero Aislado con uvx

Lanza el servidor MCP sin instalar paquetes previos; ideal en entornos corporativos restringidos (requiere uv).

Bash / MCP Wrapper
pip install uv
openlegal instalar --uvx
03 · Anatomía del Instalador Automático

Qué ocurre bajo el capó al correr openlegal instalar

1. Detecta Harnesses

Escanea si tienes Claude Code, Cursor, VS Code, Gemini CLI, Codex, OpenCode, dsh o Antigravity.

2. Fusiona sin Pisar

Agrega el servidor open-legal-chile creando respaldo .bak automático de tu JSON previo.

3. Sincroniza Mapa HF

Descarga las particiones .jsonl.gz del mapa (82.674 entradas) y arma SQLite FTS5.

4. Plugin Antigravity

Instala el plugin nativo en ~/.gemini/config/plugins/open-legal-chile/ con 27 skills.

04 · Diagnóstico Sin Falsos Positivos

Comprueba tu instalación con openlegal doctor

Inspecciona en disco versión exacta, motores OCR reales, doctrina.db, nodos de legal_knowledge_graph.json, mapa HF y el registro de las 88 herramientas MCP.

Terminal
openlegal doctor
Dentro del Chat de tu Harness
Ejecuta suite_doctor y muéstrame el diagnóstico completo del entorno.

08 · Sin Aprender 88 Nombres de Memoria

Pídelo en lenguaje natural: Mesa de Entrada (case_intake)

Cuando entregas una carpeta de expediente o cuentas un problema real, el agente invoca primero caso_analizar y después caso_ejecutar.

Prompt recomendado en tu Chat
Analiza la carpeta ./expedientes/caso_rojas y dime de qué materia se trata, qué plazos fatales corren y qué documentos faltan antes de redactar.
Alternativa directa por Terminal
openlegal caso ./expedientes/caso_rojas
09 · Garantía Anti-Alucinaciones

Toda consulta jurídica pasa por consulta_maestra + cita_texto

🔍 Orquestador Paralelo (consulta_maestra)

Consulta en simultáneo Hugging Face, doctrina canónica, grafo, normas BCN y organismos estatales (DT, CGR, SII, PJUD, CMF), devolviendo citas[] y faltantes[].

📜 Verificación Literal por Lote (cita_texto)

Antes de incluir un artículo, recupera su texto íntegro en una sola pasada de red pasando referencias: ["Código Civil art. 1545", "Ley 21.643 art. 2"].

12 · Máquina del Tiempo Legal y Cuantificación Real

BCN Histórico + Baremo Daño Moral PJUD

⏳ Normas Vigentes a Fecha Pasada

¿Necesitas saber cómo regía el Código del Trabajo o una ley en la fecha exacta de un contrato de 2018? Usa bcn_get_ley_historica o bcn_get_codigo_historico.

Prompt de Consulta Histórica
Trae el texto histórico de la Ley 19.300 vigente al 2018-06-15 con bcn_get_ley_historica y compáralo con la norma actual.

📊 8 Colecciones PJUD y Baremo

13 · Navegación Topológica (16.000 + 35.668 Nodos)

Subgrafos, Rutas y Blast Radius en LegalGraphify

Herramientas MCP del Grafo

  • graphify_consulta_subgrafo — Ficha sintética con ahorro mediano del 99,9 %.
  • graphify_trazar_camino — Ruta relacional entre dos instituciones o normas.
  • graphify_explicar_institucion — Mapa 360° + vigencia temporal + Baremo UF/CLP.
  • graphify_analizar_impacto — Qué normas y fallos afecta una reforma.

Uso Directo desde Terminal

Bash
openlegal graph "precario"
openlegal vector "resolución contrato por incumplimiento"
14 · Expedientes Escaneados e Ingesta Propia

Planificación OCR, Conversión FTS5 y Dossiers A4

1. Evaluar antes de OCR

ocr_plan_documento mide si el PDF ya tiene texto nativo para evitar demoras innecesarias; luego ocr_extract_pdf preserva fojas y tablas.

2. Ingestar Doctrina Propia

doctrina_ingestar_documento normaliza minutas/PDFs a Markdown RAE/ASALE e indexa al instante en doctrina.db y el grafo.

3. Compilar Dossier OJV

compile_legal_dossier une anexos en PDF A4 con portadas separadoras, foliado digital, marcadores TOC y salida dual liviana.

15 · Del Borrador Editable a la Auditoría Adversarial

Generar .docx, Acta 94-2015 y Crítica Goldfish

📝 Demandas e Informes en Derecho Editables

generar_documento(tipo="informe" | "demanda_civil" | "proteccion" | "laboral" | "ppa") entrega Word (.docx) A4 justificado, RAE, artículos transcritos íntegramente y código QR institucional.

🦈 Auditoría antes de Subir a OJV

Corre critique_documento(modo="goldfish") o desde CLI openlegal critique borrador.docx para detectar nulidades procesales y falta de prueba antes del traslado.

⚠️ Recordatorio de Límites

  • El estado privado en OJV requiere ClaveÚnica + CAPTCHA: consúltalo tú directamente en la web del PJUD.
  • Nunca completes manualmente un vacío marcado como faltantes[] sin verificar el archivo oficial.
  • Valida siempre como abogado habilitado antes de firmar o presentar escritos.
